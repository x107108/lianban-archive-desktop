# AMC 分类依据

核对日期：2026-11-03。分类仅用于股东信息展示和屏蔽，不修改来源原分类或将不同主体合并。

全国性 AMC 采用金融监管总局名单中的长城、信达、东方、银河、中信金融资产，兼容原披露名称及全名后的中文分公司名称。旗下投资公司、管理产品和客户账户不自动继承 AMC 身份。

企业股东仅从来源“其他”中识别具有明确公司或合伙企业组织形式、且名称未出现金融产品、资管、基金或账户等线索的主体。不将这项展示分类当作企业主营业务、最终控制人或一致行动关系的认定。
